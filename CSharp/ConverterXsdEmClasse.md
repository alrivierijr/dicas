# Converter arquivo xsd em classe do C# :

```
xsd nfse_v2-04.xsd xmldsig-core-schema20020212.xsd /c /l:CS /o:d:\temp

/l:CS     gera na linguagem CSharp
/c        geral classe
/o        arquivo de saída
d:\temp   pasta usada no exemplo
```

Para a nfse (entrar na pasta com os arquivos):
```
xscgen -o . nfse_v2-04.xsd
```
