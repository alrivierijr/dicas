# GitHub
## Comandos
### Atualizar o Projeto
```
git add .
git commit -m "Texto / Comentário"
git pull -u origin main
git push -u origin main
```

### Baixar o projeto em outra máquina
```
Clonar o diretório:
git clone https://github.com

cd seu-repositorio

Enviar de volta
git add .
git commit -m "Explique aqui o que você alterou"
git push origin main
```
